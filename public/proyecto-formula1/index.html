Arquitectura Java 17

El proyecto procesa la carrera evaluando simultáneamente los monoplazas mediante hilos concurrentes (`HiloPiloto`), considerando factores estocásticos como variaciones climáticas, degradación física de compuestos y presión psicológica entre pilotos para determinar adelantamientos y errores no forzados.

HILOS CONCURRENTES
Simulation Engine

Calcula deltas de tiempo por sector y trayectorias en paralelo, garantizando simulación en tiempo real a 60 FPS.

VARIABLES AMBIENTALES
Weather System

Simula cambios dinámicos de temperatura de asfalto y lluvia, forzando decisiones tácticas de neumáticos.

GESTIÓN DE CARRERA
Race Director

Evalúa incidentes de pista para desplegar Safety Car, banderas amarillas y ajustar deltas de velocidad de todo el pelotón.
